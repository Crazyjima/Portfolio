Gap Analysis

Where I am vs. where I need to be.

Five gaps between my current skill set and what fintech/healthcare IT roles expect, each with a concrete plan — this is the roadmap behind the Career Goals page.

1

Cloud Computing (AWS, Azure)

Currently Novice — I've deployed one static site to S3 from a tutorial, nothing independent yet. Nearly every fintech role assumes working cloud deployment experience.

Plan Enroll in the AWS Cloud Practitioner certification; deploy my personal projects (starting with the event registration app) on Azure to get hands-on with a second provider.
2

Cybersecurity Fundamentals

Currently Novice — classroom exposure only. This is non-negotiable before I'd be trusted with financial or health data.

Plan Take an online course on penetration testing basics, then practice against lab simulations (TryHackMe or similar) to build hands-on judgment, not just theory.
3

Advanced Machine Learning

Currently Beginner with Pandas/NumPy only — no modeling experience yet. Data-driven fintech products increasingly expect at least applied ML familiarity.

Plan Study TensorFlow and scikit-learn through structured courses, then apply both in a data analytics project of my own rather than stopping at tutorials.
4

Advanced Multimedia Editing

Currently Beginner in Photoshop, Intermediate in Canva — useful for polishing demo material and product walkthroughs, but I haven't touched video editing.

Plan Learn Adobe Premiere Pro and After Effects, then put it to use editing promotional videos for my student organization so the skill has a real output, not just practice files.
5

Professional Communication

Currently Intermediate — comfortable with documentation and one project defense, but not yet tested in a professional, client-facing setting.

Plan Attend workshops on technical writing and presentation skills, and deliberately practice through more detailed project documentation on future work.
